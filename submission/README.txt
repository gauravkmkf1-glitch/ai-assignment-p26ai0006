How to run
----------
1. Open reasoning_agent.ipynb in Jupyter (python3 kernel; only the standard
   library + pandas are required for the full evaluation).
2. Run all cells top to bottom:
     setup -> Parts 1-4 (engines) -> smoke tests & traces ->
     evaluation (prints FINAL accuracy and inference time) ->
     submission.csv generation.
3. The evaluation uses ./data if present, otherwise downloads the public
   Hugging Face sets once (RuleTaker, CounterBench, FOLIO). Fully offline
   runs still execute the smoke tests and traces.

Regenerating submission.csv for the private test
------------------------------------------------
Place the private test file next to the notebook (or in ./data) as
private_test.csv or test.csv with columns:
  id,  context (or premises / given_info / kb / theory),
       statement (or question / query / conclusion / claim)
Column names are auto-detected (case-insensitive); extra columns are
ignored. Re-running the last cell writes submission.csv with columns
id,predicted_label (True/False), one row per input row, in input order.
Without such a file, the notebook writes a demo-format submission.csv
from public samples (same two-column format).

System overview
---------------
NL knowledge base + query -> style router -> internal representation ->
classical reasoning -> True/False:
  * RuleTaker style -> Horn clauses -> forward-chaining least-fixpoint
    closure with negation-as-failure + contradiction retraction; backward
    chaining with unification for traces.
  * CounterBench style -> structural causal model -> Pearl's
    abduction-action-prediction (exhaustive root search, do(),
    fixed-point propagation).
  * FOLIO style -> FOL (gold annotations or NL template parser) -> NNF ->
    Skolem CNF -> resolution refutation (unification, factoring,
    subsumption, set-of-support). No proof within budget -> False.
Any parse/proof failure abstains (-> False); the agent never crashes and
never consults a generative model.
